# 근거·번역·이미지 관리

이 프로젝트는 성인 당뇨병 전단계와 2형 당뇨병을 위한 일반 교육 자료입니다. 의료진·약사의 별도 임상 검수를 마친 제품이라고 표시하지 않습니다.

## 근거

- `content/sources.mjs`: 확인한 지침·공공기관 교육·문헌고찰·미국 허가사항의 링크와 검토일.
- `content/research.mjs`: 대표 원저 연구의 결과와 적용 한계. 모든 논문을 전수 수록하지 않습니다.
- `content/book.mjs`: 본문·오늘 할 행동·주의점·근거 ID. 한국어/영어/베트남어는 같은 ID를 공유합니다.
- 외부 지침 표·그림을 복제하지 않으며 설명은 독자용으로 재작성합니다.
- 혈당·체중의 대리지표 개선을 심혈관·신장 결과 개선과 구분합니다. 관찰연구, 인과효과, 허가 경고를 혼동하지 않습니다.
- 연구 해석·허가사항은 정기적으로 사람이 재확인해야 합니다. 자동 문헌 검색·자동 게시 기능은 없습니다.

## 약물 확인

`content/drugs.mjs`의 42개 성분은 교육 목적의 제한된 목록입니다. 언어 선택은 국내외 승인 상태를 뜻하지 않습니다. 제품명·국가별 함량·서방형·주사 농도·새로운 성분은 해당 제품의 식약처 또는 현지 허가사항에서 확인합니다. 미국 허가자료를 국내 제품 허가 확인으로 표시하지 않습니다.

모든 성분별 부작용 빈도를 전수 수록한 데이터베이스가 아닙니다. 기본 계열 설명과 검증한 성분별 주의사항만 표시합니다. 발생 확률을 계산하거나 약을 중단·변경하는 기능을 추가하지 않습니다. 새로운 별칭은 정확히 식별할 수 있을 때만 추가하고 시험으로 중복·오분류를 확인합니다. 모르는 성분·제품명은 부분 문자열로 자동 매칭하지 않습니다.

복합제는 약봉투에 표기된 성분을 모두 `+`, 쉼표, `/`, 줄바꿈으로 입력합니다. 브랜드만 보고 성분을 추정하지 않습니다. 입력 함량은 이름 식별에서 제외되므로 결과가 용량·제형 위험을 검증했다는 뜻이 아닙니다.

`1,000mg`의 천 단위 쉼표와 `100단위/mL`·`0.25mg/0.5mL` 같은 농도 표기는 구분 기호로 보지 않습니다. 함량·제형만 있는 조각(`500mg`, `XR`)은 미확인 성분으로 표시하지 않습니다. `정`·`캡슐`·`주` 같은 제형 접미사와 `염산염`·`타르타르산염`·`hydrochloride` 같은 염 접미사는 떼어낸 나머지가 지원 성분명과 정확히 일치할 때만 인식합니다. 띄어쓰기로 나열한 입력은 모든 단어 묶음이 지원 성분명일 때만 나눕니다. 하나라도 모르는 단어가 있으면 입력 전체를 미확인으로 남깁니다. 별칭에는 숫자를 넣지 않습니다(함량 제거 규칙과 충돌).

## 번역 유지

한국어 원문·공통 UI·약물 설명·연구 설명을 수정하면 `translation-review.json`의 지문과 달라져 배포 시험이 실패합니다. 영어·베트남어를 함께 수정하고 의미를 대조한 뒤에만 아래 명령으로 기록을 갱신합니다. 현재 번역은 독립적인 의료 전문 번역 검수를 받지 않은 교육용 초안입니다.

```sh
node scripts/build.mjs --record-translation-review
npm run check
```

`--record-translation-review`는 번역을 수행하거나 의학적 정확성을 보증하는 명령이 아닙니다. 검토 결과를 기록할 뿐입니다.

## 이미지

설명 페이지 9개에 서로 다른 일러스트 1장씩 배치합니다. 안경·갈색 단발·청록색 옷을 입은 같은 중년 여성 캐릭터를 사용합니다. 생성한 정적 애니메이션 스타일 이미지이며 움직이는 영상이나 GIF는 아닙니다. 생성 이미지의 기관 아이콘은 개념을 돕는 표현으로 실제 해부학 도해·진단 자료가 아닙니다. 숫자·약 이름·복용량은 이미지에 넣지 않으며 의학적 설명은 번역 가능한 HTML 캡션에 둡니다.

저혈당 그림: 의식이 있고 삼킬 수 있는 경우만 설명합니다. 정제 개수는 용량이 아닙니다.
당뇨발 그림: 신경 감각 저하·작은 상처와 거울을 이용한 확인을 설명합니다. 사진으로 진단하거나 상처를 직접 처치하도록 안내하지 않습니다.

## 검증

Node 기본 시험으로 성분·별칭·조합·미확인 입력, 번역 누락·지문, 내부 링크·앵커, 이미지, EPUB ZIP 구조를 확인합니다. 실제 브라우저에서 언어·모바일·입력 결과·검색·인쇄를 추가 확인합니다. 이런 검사는 임상 검수를 대신하지 않습니다.

- 겜피브로질·클로피도그렐은 결과에서 이름과 제한된 확인 범위를 표시합니다. 레파글리니드 관련 규칙 외의 모든 상호작용을 확인하는 기능은 아닙니다.
- 미글리톨의 미국 허가사항에 근거한 포도당 대처 규칙을 추가했습니다.

- 읽기 기록을 지우면 현재 페이지에서는 예약 저장·스크롤·페이지 종료 저장을 중단합니다. 다른 설명 페이지에서 새로 읽으면 새 기록을 시작합니다.
