# 🩺 혈당과 함께 살아가기

당뇨약을 복용 중인 환자를 위한 **웹 전자책**입니다.
중고등학생도 이해할 수 있는 쉬운 말로 당뇨병·당뇨약·건강기능식품·생활습관·운동법을 정리했습니다.

## 목차

| 챕터 | 내용 |
|------|------|
| 1장 | 당뇨병, 쉽게 이해하기 — 혈당·인슐린의 원리, 1형/2형, 합병증, 진단 기준 |
| 2장 | 내가 먹는 당뇨약 완전 정리 — 메트포르민부터 인슐린까지 계열별 원리와 주의사항 |
| 3장 | 연구로 검증된 건강기능식품 — 근거 수준별로 솔직하게 구분 |
| 4장 | 혈당을 잡는 생활 습관 — 거꾸로 식사법, 식후 걷기, 수면·스트레스 관리 |
| 5장 | 혈당을 잡는 운동법 — 유산소·근력 루틴, 주간 계획표, 저혈당 예방 수칙 |
| 6장 | 실전 가이드 — 15-15 저혈당 대처법, 자가혈당 측정, 정기 검사, FAQ |

## 기술 구성

- 순수 HTML / CSS / 약간의 JavaScript — **빌드 과정이 전혀 필요 없는 정적 사이트**
- 모바일 반응형, 읽기 진행 바, Pretendard 웹폰트
- `index.html`(목차) + `chapter1~6.html` + `css/style.css` + `js/main.js`

## Vercel 배포 방법

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New → Project** 클릭
3. 이 레포지토리(`Diabetes`)를 Import
4. Framework Preset은 **Other**(기본값), 별도 설정 없이 **Deploy** 클릭
5. 끝! 정적 사이트라 빌드 설정이 필요 없습니다.

로컬에서 미리 보려면 레포 폴더에서:

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

## 면책 조항

이 전자책은 일반적인 건강 정보 제공을 목적으로 하며, 의사의 진단·처방을 대신할 수 없습니다.
약 복용 변경, 건강기능식품 섭취, 새로운 운동 시작 전에는 반드시 담당 의사·약사와 상의하세요.
